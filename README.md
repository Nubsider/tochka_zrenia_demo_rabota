# Точка зрения — журнал о дизайне

Редизайн существующего сайта на HTML, CSS и JavaScript. Для запуска откройте `index.html` в современном браузере. Установка и сборка не требуются: Montserrat и вся графика подключены локально.

Актуальный источник: [Portfolio → TOCHKA ZRENIA → Desktop - 1](https://www.figma.com/design/HZnCSB6X6NjTe1Sk1tq6DT/Portfolio?node-id=2-327), узел `2:327`, 1440 × 4747 px. Цвета, типографика, слои, Auto Layout, состояния компонентов и исходная графика изучены через Figma MCP. Старый макет из прежней версии README не использовался.

Обновлены обложка, интервалы, оформление карточек, теги и авторы, трёхколоночная сетка «Выбора редакции», положение бегущей строки, карточки «Дизайн сегодня», стрелки и подвал. Палитра раздела Color Style вынесена в CSS-переменные. В `assets/figma` сохранены 15 оригинальных PNG и три SVG состояния стрелки. Сохранились существующий локальный Montserrat и лицензия OFL.

Сохранены фильтры, просмотр анонсов, карусель со стрелками и клавиатурой, мобильное меню, вход, checkbox, демонстрационная подписка, уведомления, якоря, бегущая строка, появление секций и кнопка «Наверх». Селекторы и обработчики действующих функций сохранены. Серверная авторизация, рассылка и полные тексты статей по-прежнему не подключены; формы не отправляют и не сохраняют данные.

Проверено в Chromium на ширинах 1440, 1024, 768, 390 и 320 px: отсутствие горизонтального переполнения и наложений в шапке, загрузка изображений и шрифта, все 13 фильтров, все 14 анонсов, диалоги, формы, ссылки, карусель, мобильное меню, анимация строки и режим уменьшения движения. Ошибок JavaScript, консоли и загрузки ресурсов не обнаружено. Десктопный скриншот сопоставлен с актуальным Figma, после сравнения исправлены расхождения.

На странице Figma отсутствуют мобильные и планшетные варианты. Адаптивная компоновка разработана на основе десктопной системы: меню сворачивается при ширине до 900 px, карточки перестраиваются без потери функций. Возможны небольшие отличия сглаживания шрифта и дробного округления размеров между Figma и браузером. Проверки в Firefox, Safari и на физических мобильных устройствах не выполнялись.

Файлы: `index.html` — структура страницы; `styles.css` — оформление и адаптивность; `script.js` — данные и поведение; `assets/figma` — изображения, SVG и шрифт. Зависимости, окружение и конфигурация публикации не изменялись. Публикация и отправка изменений в GitHub не выполнялись.
