# Точка зрения — верстка по Figma

Откройте index.html в браузере. Установка не требуется, шрифт и иллюстрации подключены локально.

Источник: Figma, файл 70RSakRfTBnm1wPoH3pDut, экран Desktop - 2 (189:143), 1440 × 4557. Тексты, Montserrat, цвета и размеры разделов сверены со слоями Figma. Мобильная компоновка разработана дополнительно, поскольку передан настольный макет.

Работают фильтры, карусель, мобильное меню, просмотр анонсов и меню входа. Форма входа повторяет узлы Figma «Меню Вход» (392:163) и «Check box» (397:165): открывается сверху, затемняет страницу и содержит два состояния галочки. Авторизация, полные статьи, страницы школы и рассылка не подключены: этих данных и сервисов нет в переданном макете. Email и пароль не отправляются и не сохраняются.

Обложка и 11 иллюстраций экспортированы из Figma. Три изображения — references.png, interface.png и three-d.png — остаются вырезками из исходного PNG: экспорт остановился из-за лимита Figma Starter. Их можно заменить оригиналами с теми же именами.

Проверено в браузере на ширинах 1440 и 390: работа фильтров, мобильное меню, загрузка изображений, отсутствие горизонтального переполнения на мобильном экране. Онлайн-публикация не выполнена.

Файлы: index.html — разметка; styles.css — стили; script.js — поведение; assets/figma — изображения и Montserrat (лицензия OFL приложена).

Код оформлен в простом учебном стиле: разметка разбита на понятные блоки, CSS записан построчно, а JavaScript разделён на небольшие функции с обычными именами и комментариями.

Стрелки карусели заменены с текстовых символов на изображения из исходного макета: 44 × 44 px, зазор 14 px. SVG-экспорт недоступен из-за лимита Figma.
